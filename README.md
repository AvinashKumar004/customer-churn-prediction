# 📊 Customer Churn Prediction System

## 🚀 Project Overview
Customer churn is one of the biggest challenges for telecom and subscription-based companies.  
This project builds a **Machine Learning model** to predict whether a customer will leave (churn) or stay.

The goal is to help businesses take **proactive actions** to retain customers and reduce revenue loss.

---

## 🎯 Objectives
- Analyze customer data to identify churn patterns  
- Build a predictive model to classify churn vs non-churn  
- Evaluate model performance using accuracy and metrics  
- Deploy a simple app for real-time predictions  

---

## 🛠️ Tools & Technologies
- Python 🐍  
- Pandas & NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  
- Streamlit (for deployment)  

---

## 📂 Dataset
- Telco Customer Churn Dataset  
- Includes customer demographics, services, and account details  

---

## 🔍 Steps Performed

### 1. Data Preprocessing
- Handled missing values  
- Converted categorical variables  
- Feature scaling  

### 2. Exploratory Data Analysis (EDA)
- Analyzed churn distribution  
- Identified key features affecting churn  

### 3. Model Building
- Applied Machine Learning algorithms  
- Trained and tested the model  

### 4. Model Evaluation
- Accuracy Score: **~99%**  
- Confusion Matrix  
- Classification Report  

---

## 📈 Results & Insights
- Customers with **high monthly charges** are more likely to churn  
- Long-term customers are less likely to leave  
- Certain services strongly influence churn behavior
